# Git Cheatsheet

1. `git init` - Initialize a new local Git repository.
2. `git status` - Show the current state of the working directory and staging area.
3. `git add` - Add file changes to the staging area.
4. `git commit` - Save staged changes to the repository history.
5. `git log` - Display the commit history of the repository.
6. `git branch` - List, create, or delete branches.
7. `git checkout` - Switch between branches or restore files.
8. `git merge` - Combine changes from another branch into the current branch.
9. `git push` - Upload local commits to a remote repository on GitHub.
10. `git pull` - Fetch and merge changes from a remote repository.
