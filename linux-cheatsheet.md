# Linux Cheatsheet

1. `ls` - List files and directories in the current folder.
2. `cd` - Change the current working directory.
3. `pwd` - Print the full path of the current directory.
4. `mkdir` - Create a new directory.
5. `touch` - Create a new empty file.
6. `rm` - Remove files or directories.
7. `cp` - Copy files or directories from one place to another.
8. `mv` - Move or rename files and directories.
9. `cat` - Display the contents of a file in the terminal.
10. `grep` - Search for specific text patterns inside files.
